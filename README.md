# Hermanos Mendez Construction Management, LLC

Static website for **HMCM** — consulting (commercial and residential, plus other consulting services), construction management, and project management for land development and construction in Tampa Bay.

Canonical host: **https://hmcmfl.com**

This repo is portable HTML, CSS, JavaScript, and assets. There is no required build step to serve the site. `tools/build.py` regenerates pages if you are editing content.

## Local preview

```bash
python3 -m http.server 8080 --directory .
```

Open http://localhost:8080

## Deploy

Upload the repository contents (keep the folder structure) to any static host. `index.html` must sit at the host’s site root so `https://hmcmfl.com/` serves the home page. This repository does not include GitHub Pages, a CNAME, or DNS records.
